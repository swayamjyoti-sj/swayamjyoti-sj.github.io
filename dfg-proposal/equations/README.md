# DFG equations visual atlas

This is a standalone GitHub Pages–ready site of all **30 displayed mathematical blocks** found in `proposal_revised.tex`. Open `index.html` in a browser with internet access to render equations through MathJax CDN.

Upload the entire `dfg-equations-visual-guide/` directory as a sibling of your `dfg-proposal/` folder, or copy its files into `dfg-proposal/equations/`. The recommended site address is `/dfg-proposal/equations/`.

The source LaTeX remains unchanged. Equations are extracted as original LaTeX snippets and label tags removed only for web rendering. Captions and transfer notes are interpretive summaries.
