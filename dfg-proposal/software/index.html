Software for scale bridging

Open reference code, scientific validation plans and production software requirements, from atomic event catalogues through physical kinetics and stochastic elastoplasticity to continuum finite elements and cohesive fracture.

Software maturity: These six accessible Python files are runnable reference demonstrations, not the complete ARTn, AQS, 3D elastoplastic finite-element, phase-field or fracture solvers. The research must build, benchmark and validate those production implementations. Their illustrative parameters are not newly measured simulation results.

Reference code and tests

01 · Atomistic event catalogue

Minimum–saddle–minimum records, forward/reverse barriers and basic directed duplicate checks. Not an ARTn engine.

catalogue.py

02 · Activated kinetics

Barrier-conditioned rates, competing probabilities and Gillespie first-event sampling.

kinetics.py

03 · Mesoscale accounting

Integrated transformation moments and volume-averaged plastic shear. Not a spatially interacting solver.

mesoscale.py

04 · Continuum and decohesion

Simple RVE work consistency, Mode-I bilinear cohesive traction, damage envelope and 1D bar equilibrium illustration.

continuum.py

05 · HPC workload estimates

Job counts, number of cores, core-hours and transparent budget totals.

estimate.py

06 · Numerical unit tests

Regression checks on barrier directions, rate normalization, moment transfer, RVE work and separation energy.

test_reference.py

Run locally

Download all six files into one directory named code. Python 3, standard library only.

cd code
python catalogue.py
python kinetics.py
python mesoscale.py
python continuum.py
python estimate.py
python -m unittest discover -s . -p "test_*.py"

Candidate production components include LAMMPS for molecular mechanics, a validated ARTn implementation, NEB and a suitable open FEM framework. Selection and licensing are subject to installation, integration and numerical benchmarks; the included files do not claim these engines are installed.

Critical transfer contracts

Atomic → kinetic → mesoscale

Carry: unique barrier/free-energy paths, prefactors, orientations, transformation tensors, structural state, uncertainty.

Discard: discovery counts as physical rates and raw atomistic trajectories not required by the closure.

Mesoscale → continuum → fracture

Carry: work-conjugate averaged stresses, consistent tangents, dissipation, internal states and closure uncertainty.

Do not infer: cohesive strength, fracture energy or crack path simply from an atomic LSE or a shear-band contour. Separation properties require independent calibration.
