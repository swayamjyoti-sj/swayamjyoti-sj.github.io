# S. Swayamjyoti portfolio with DFG proposal page

This package updates the main portfolio website and adds a dedicated `dfg-proposal/` subpage.

## What changed
- The portfolio's **DFG Proposal** navigation link now opens a dedicated page at `dfg-proposal/`.
- The proposal preview on the homepage is populated with real proposal title, summary, objectives and work packages.
- A new subfolder `dfg-proposal/` contains:
  - a standalone proposal webpage
  - colourful flowcharts and work-package diagrams
  - proposal figures from the uploaded archive
  - downloadable source files and original ZIP

## GitHub upload
Upload **all files and folders** in this package to the root of your GitHub Pages repository.
The `dfg-proposal/` folder must remain as a folder in the repository.
