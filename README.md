# S. Swayamjyoti portfolio with research proposal page

This package updates the main portfolio website and adds a dedicated `metallic-glass-research/` subpage.

## What changed
- The portfolio's **Metallic Glass Research** navigation link now opens a dedicated page at `metallic-glass-research/`.
- The proposal preview on the homepage is populated with real proposal title, summary, objectives and work packages.
- A new subfolder `metallic-glass-research/` contains:
  - a standalone proposal webpage
  - flowcharts and work-package diagrams
  - research proposal figures
  - downloadable source files and original ZIP
